# Portfolio Evidence MCP

给复盘模型提供资料，而不是预写结论。这个本地 STDIO 服务只提供 [`bundle/`](bundle/) 内经审阅、脱敏的摘录。它不扫描原仓库、不监听端口，也不提供读取任意路径、执行命令或写文件的工具。

| 工具 | 输入 | 输出 |
| --- | --- | --- |
| `list_evidence` | 无 | 9 项证据的编号、类型、脱敏引用路径，不含正文 |
| `read_evidence` | 一个 `evidence_id`，例如 `storage` | 对应摘录和行号，可引用 `[storage:6-10]` |

服务只接受目录里的 ID。启动时校验目录摘要，读取时校验路径范围与摘录摘要（按 LF 规范化后计算 SHA-256）。摘要不能替代脱敏审查，也不防有权修改服务代码的本机用户。示例中的路径、名称和数字为脱敏替代；测试源码和 CI 配置都不等于运行回执。

## 本地验收（Windows / PowerShell）

在此目录使用 Python 3.11+。先安装依赖（可能需要访问包源），再运行无需联网、不调用模型的自检：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -B verify_mcp.py
```

自检通过真实 MCP 客户端启动子进程，核对握手、工具发现、9 项带行号的读取，以及未知 ID、绝对路径、越界输入、摘录和白名单篡改的拒绝行为。文件链接测试只操作临时副本；环境不能创建链接时会明确显示 `SKIP`。如需在终端查看指定摘录，可在命令末尾加 `--evidence hourly-job storage`。

## 接到 STDIO 客户端

参照 [配置示例](codex-mcp.example.toml)，把 Python 和脚本的两处路径都换成本机绝对路径。其他支持 STDIO 的客户端使用同一启动命令：虚拟环境的 Python，参数为 `-I -B` 和 `evidence_mcp.py` 的绝对路径。

可以问模型：「这个历史趋势功能，下周只选一个问题复盘，你会选什么？先列证据，再读取必要的摘录；用证据 ID 和行号解释结论，给出一个能证伪的实验。」例如，`hourly-job` 显示先删后插，`storage` 显示写入各自提交。这支持“途中失败可能导致旧小时桶消失”的推断，不证明生产环境发生过事故。

服务本身不发模型请求；连接远程模型的客户端可能把读出的摘录发给模型提供方。换材料时先人工脱敏，再更新清单和相应的 SHA-256；不自动纳入新文件。不要放入原始项目、真实业务数据、内部路径、运行日志或凭据。本机配置、环境和联调回执不提交。
