# STAR 输出模板

> 每条经历按四要素产出。根据用户要的输出类型（简历/档案/面试），展开程度不同。

## 简历版（1-2 行，强动词 + 数字）

格式：`<动词> <做了什么>，<量化结果>`

示例：
- 重构 refresh token 轮换：行锁 + 重放检测批量吊销，消除并发刷新双发令牌竞态；284 测试函数覆盖
- 独立交付自托管 AI 巡检平台：FastAPI + React + Go agent，235 项回归 + 25 组件测试 + 三平台 CI
- 设计统一充值网关双接入模式：QuickPay Bearer / Standard HMAC，幂等租约令牌轮转接管

## 档案版（四要素展开 + 难点四要素）

```
### 项目：<名>
- 角色：<独立开发/主力/协作>
- 规模：<X commits / Y 文件 / Z 测试>

**S 背景**：...
**T 任务**：...
**A 行动**：
- <动词> <做了什么>（文件:行号 或 模块名）
- ...
**R 结果**：<数字/状态/验证方式>

**难点 N：<一句话现象>**
- 现象：...
- 定位：...
- 根因：...
- 解法：...
- 验证：...
```

## 面试版（90 秒讲述 + 追问弹药）

```
### 项目：<名>（90 秒版）
<一句话定位 + 架构一句话 + 一个亮点 + 一个数字>

### 追问弹药
- Q: <面试官可能问什么>
  A: <怎么答，引用档案里的难点>
- Q: ...
  A: ...
```

## 通用规则

- **动词开头**：设计/重构/优化/攻坚/落地/主导/独立交付
- **删流水账**："负责/参与/协助" 改成具体动词
- **数字必核实**：数代码、查 git log、读 docs；数不到就写"无量化数据"
- **标边界**：独立 / 协作 / AI 辅助
- **脱敏**：商业项目不写客户/域名/产品名
