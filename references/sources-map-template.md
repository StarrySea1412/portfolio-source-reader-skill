# 来源地图模板

需要长期维护多项目来源时，把这份模板复制到用户允许保存的位置，通常命名为 `SOURCES.md`。已给仓库或现稿时可以直接查找，无需先补全地图。

```markdown
# 项目来源
- 相对路径基准：本地图所在目录

### <项目展示名>
- 类型：<工作 / 个人 / 上游二开 / 研究>
- 定位：<本地相对路径、获准访问的 URL 或内部安全别名>
- 原称、上游或同源副本：<需要区分时填写>
- 档案或索引：<相对路径>
- 实现入口：<依赖、关键模块或相关提交>
- 验证入口：<基准、测试运行或验收报告，标明历史版本或日期>
- 本人责任：<已确认的范围和依据；缺证项>
- 时间：<明确是项目时间或已确认任职时间>
- 披露范围：<获准披露的名称、事实和引用>
```

路径、角色或验证口径变化时更新对应条目。真实地图按材料的披露范围保管，公开示例用虚构名称与占位路径。
