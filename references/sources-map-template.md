# SOURCES.md 模板

把地图放在自己的受控工作区。它只负责定位，不授予访问权限，不保存凭据或真实业务数据。只复盘一个仓库时，不必建地图；需要写时，每个项目至少填一个入口即可。

```markdown
# 项目来源

## <项目代号或名称>

- 入口：<本地目录、档案路径或公开仓库 URL，至少一个>
- 补充来源（可选）：<源码子目录、评测记录、发布记录等>
- 核对范围（可选）：<分支、提交、日期或环境>
- 使用边界（可选）：<只供本人复盘、不对外；只读某目录等>
```

相对路径以**实际的 `SOURCES.md` 所在目录**为准。给出某个文件或子目录能缩小检索范围；不要为了补齐表格去统计项目规模。同一项目的仓库副本、上游和自己的改动请标明关系，不把复制仓库当成独立贡献。

项目档案可以补充背景，但不是所有结论的证据。来源变化时更新路径；事实变化时重新核实对应版本，不覆盖旧版本明确留存的结果。参照 [虚构示例](../assets/sources-map.example.md) 填写。
