# 项目信息源地图

> 定位入口，不替代事实、个人贡献或材料授权的核实。地图是用户项目资料的一部分；skill 中的示例不是真实配置。

- 地图所在目录：<档案根目录；可使用 .>
- 源码根目录：<可选；绝对路径>
- 最近定位日期：<YYYY-MM-DD；只表示入口核查>

## 使用

先用已知路径与现有档案，再补确实缺失的信息。相对档案路径以本文件所在目录解析；源码路径以声明的源码根目录或本文件所在目录解析。用户指定单个项目时只定位该项目。

## 项目

```text
### <项目名 / 安全别名>（一句话定位）
- 类型：工作 / 个人 / fork / 练习 / 研究
- 本地路径：<实际路径；未找到写“未定位”>
- 本地来源状态：<已定位 / 未定位 / 不可访问；核查日期>
- 源码快照：<HEAD；工作树有无修改；可选 shallow/worktree 信息>
- 远端位置：<安全链接 / 未登记；链接不证明公开性>
- 档案：<相对路径 / 未建档>
- 关键入口：<实际存在的 1–3 个文件或目录>
- 采集问题：<本次最值得回查的机制、难点或结果>
- 本人贡献：<已有说明来源 / 待本人确认>
- 材料边界：<允许披露的范围 / 待确认>
- 历史结果：<证据卡或档案引用；避免复制无日期的数字>
```

不必填完整表才开始采集。无法定位的项目保留缺口，不用相近名称仓库代替。

- `<实际路径/安全别名>`：<同一项目副本 / 上游 / 仅研究；归并到哪个条目>

## 维护

路径迁移或结论变化时更新对应入口与证据卡。新地图先检查路径、仓库身份与材料边界；来源可达、提交总数和最后日期都不证明成果或个人贡献。
